\section{Overview}

This chapter reports the IS/OOS comparison using the parameters selected in Chapter 5. The main
comparison is between two workflows: the standard workflow, optimized on the real historical IS period,
and the synthetic workflow, optimized on synthetic IS paths. For MA Cross, an additional validation
table is also shown to compare the real IS result with the synthetic-mean IS result using the same
parameters.

In all tables, \(Diff = OOS - IS\). This is the most important row, because it measures the change from
backtested performance to OOS performance. For net profit, Sharpe, and average profit, a negative value
means that OOS performance was worse than IS performance. For max DD, a negative value means that
drawdown became larger OOS. The key comparison is between the standard workflow and the synthetic
workflow, because both are tested on the same OOS data.

For MA Cross, the synthetic workflow does not improve the IS/OOS gap. Net profit deteriorates more than
in the standard workflow (\(-57.94\) versus \(-38.49\)), and OOS net profit becomes negative. The Sharpe
gap is slightly smaller for the synthetic workflow (\(-0.59\) versus \(-0.64\)), but the OOS Sharpe is
still worse. For this strategy, the synthetic workflow does not improve the final OOS result.

The dollar metrics need one important caveat. The tests use a fixed size of one lot. Since AAPL trades
at higher prices in the OOS period, the same one-lot trade naturally creates larger dollar gains and
losses. This affects net profit and average profit, so those values are not enough by themselves to
judge generalization. Sharpe and max DD percentage are more useful here because they are less
dependent on the price level. For this reason, the Std MRev comparison is based mainly on Sharpe and
max DD rather than dollar profit.

On Sharpe, the standard workflow shows no deterioration: the gap is \(+0.10\). The synthetic workflow
shows a deterioration of \(-0.14\). For Std MRev, the historically optimized parameters therefore
generalize at least as well as the synthetically optimized parameters.
